## 📖 نبذة عن المنصة (About The Platform)

**مكتبة سكولار الأكاديمية** هي منصة تخصصية رائدة تقدم الدعم العلمي والتنسيقي لطلبة الجامعات والمعاهد والدراسات العليا. ترتكز المنصة على أعلى معايير الضبط الأكاديمي، السرعة الفائقة في الإنجاز، والمتابعة الدقيقة لملاحظات الأساتذة المشرفين ولجان المناقشة الرسمية.

صُممت المنصة وفق **دستور ومانيفستو مدرسة INK للتصميم الرقمي فائق الحرفية (Bespoke High-Craft Web Engineering)** بعيداً عن القوالب الجاهزة أو التدرجات الركيكة، مع معمارية ألوان صامتة (`Solid Color Architecture`) مستوحاة من رصانة التدرج النيلي الملكي، ودعم كامل للثنائية اللغوية الحقيقية (عربي RTL / إنجليزي LTR).

> **Scholar Academic Library** is an executive bespoke digital platform tailored for researchers and university students. It provides accredited manuscript layout for student-written theses, peer-reviewed source curation across all disciplines, and precision scientific translation in strict adherence to university style manuals.

## 📜 ميثاق الأمانة والنزاهة العلمية (Academic Integrity Charter)

تلتزم المنصة بميثاق أخلاقي وشرعي صريح لا يقبل المساومة، وتعلن براءة الذمة التامة من أي ممارسات تخل بقدسية العلم:

> **«لا نعمل في إعداد أو بيع البحوث والرسائل الجاهزة إطلاقاً، ولا نكتب نيابة عن الباحث، إيماناً بحرمة ذلك شرعاً وأكاديمياً.»**

### الاستدلال بالهدي النبوي الشريف:
* قال رسول الله ﷺ: **«المُتَشَبِّعُ بِمَا لَمْ يُعْطَ كَلَابِسِ ثَوْبَيْ زُورٍ»** *(متفق عليه: رواه البخاري ومسلم)*.
* وقال عليه الصلاة والسلام: **«مَنْ غَشَّنَا فَلَيْسَ مِنَّا»** *(رواه مسلم)*.

ينحصر نطاق عملنا التخصصي في:
1. **إعداد وتنسيق بحوث البكالوريوس ورسائل الماجستير المكتوبة**: ضبط الهوامش، نمط الخطوط، الفهارس الآلية، الترقيم الأكاديمي، والتدقيق اللغوي لمخطوطة الطالب الأصلية وفق دليل جامعته.
2. **جمع وتوثيق المصادر لكافة التخصصات**: استخراج الأوراق العلمية المحكمة والمراجع الحديثة وفهرستها بنظم التوثيق العالمية (APA, IEEE, Harvard) مع روابط DOI المعتمدة.
3. **الترجمة الأكاديمية التخصصية**: ترجمة علمية دقيقة للمستندات والأبحاث والملخصات خالية تماماً من الركاكة ومشاكل الترجمة الآلية.

## ✨ المميزات الرئيسية (Key Features)

### 1. 🏛️ مسرح ثلاثي الأبعاد للخدمات بطباعة نصية فاخرة (Pure Typographic 3D Stage)
- مسرح تفاعلي انسيابي مبني بمحرك **Three.js** يعرض الخدمات الأكاديمية الثلاث ببطاقات صامتة ذات تباين طباعي مدروس وخالية تماماً من الشعارات الزائدة أو الرسوم المبتذلة.
- تفاعل فيزيائي ناعم يدعم السحب واللمس (Drag & Touch Swipe)، وتكبير البطاقة المختارة تلقائياً (Tap-to-focus) بدون أزرار سفلية مشتتة.
- خامات مجسمة مؤطرة بالذهب الملكي المعتق (`Champagne Gold Border`) تطفو بسلاسة فوق الخلفية النيلية.

### 2. ⚡ شبكة الهيكل المؤقتة الفاخرة (Architectural Skeleton Grid)
- مرحلة تحميل معمارية سريعة تطابق الأبعاد الفيزيائية لبطاقات الـ 3D وتوفر وميضاً ضوئياً خافتاً (`Skeleton Shimmer`) أثناء تهيئة الرسوميات.
- تلاشٍ ناعم وفوري عند جاهزية المشهد لضمان انعدام القفزات البصرية أو التقطيع على مختلف سرعات الاتصال.

### 3. 📋 ملف الإرسال الأكاديمي المباشر (Luxury Dispatch Dossier)
- استبدال المعاينة التقليدية بملف إرسال متكامل يحتوي على:
  - **رادار حالة حي** (`Live Dossier Status`) مع نبض ضوئي أخضر.
  - **خلايا بيانات منظمة (Metadata Chips)** تفرز الخدمة، الجامعة، اسم الباحث، والملاحظات.
  - **صندوق إبراز عنوان وموضوع الدراسة** بخط هندسي مريح.
  - **شفرة الإرسال المجهزة** للتواصل الفوري مع زر نسخ بنقرة واحدة وتوجيه مباشر لواتساب أو تليغرام.

### 4. 🌐 محرك ثنائي اللغة حقيقي (Dynamic Bilingual & Bidi Engine)
- تبديل فوري وسلس بين العربية (RTL) والإنجليزية (LTR) مع تبديل تلقائي للأصول البصرية (`logo-ar.png` و `logo-en.png`).
- استخدام صارم للخصائص المنطقية الحديثة (`margin-inline`, `padding-inline`, `inset-inline`) مع موازنة الارتفاع البصري للأسطر العربية لمنع تداخل الأحرف.

### 5. 🛡️ ضمان التسليم المزدوج (Dual Delivery Standard)
- تسليم كل عمل بصيغتي **Microsoft Word** (.docx قابلة للتعديل بضوابط الكلية) و **Adobe PDF** (.pdf نسخة نهائية ثابتة جاهزة للمناقشة والطباعة).

## 🎨 الهوية البصرية ونظام التصميم (Design System)

تم بناء الواجهة بالاعتماد على لوحة ألوان ملكية صامتة (`Solid Architecture`) متناسقة مع التدرج النيلي:

| المتغير اللوني | القيمة اللونية | الوصف والاستخدام |
| :--- | :---: | :--- |
| `--scholar-navy-solid-base` | `#0A1322` | الكحلي الملكي المصمت (خلفية أساسية فاخرة) |
| `--scholar-navy-dark` | `#101E36` | درجات العمق المعماري لبطاقات الضمانات |
| `--scholar-navy-card` | `#0E1B30` | لون البطاقات الصامتة وميثاق الأمانة |
| `--scholar-navy-quote` | `#0A1526` | الخلفية الصامتة لصندوق الأحاديث النبوية |
| `--scholar-sapphire-bright`| `#2B66CC` | الأزرق الياقوتي المتناسق للعناصر التفاعلية |
| `--scholar-accent-gold` | `#C5A059` | الذهبي الأكاديمي المعتق للشارات والإطارات |
| `--scholar-cream-bg` | `#F8FAFD` | أسطح البورسلان النقي للقراءة الفائقة |

### 🖋️ مصفوفة الخطوط المتوازنة (Curated Typography)
- **العناوين الرئيسية الحديثة**: *Alexandria* بتدرج أزرق وأبيض متناسق (`White to Blue Sapphire Gradient`).
- **نصوص الأحاديث والافتتاحيات**: *Amiri* الرصين بارتفاع أسطر بصري مريح.
- **القراءة والواجهات**: *IBM Plex Sans Arabic* و *Outfit* لضمان أعلى مقروئية على شاشات الجوال والحواسب.

## 📁 هيكل المشروع (Project Structure)

```text
scholar-library/
├── index.html                   # الهيكل الدلالي للمنصة وملف الإرسال وميثاق الأمانة
├── logo-ar.png                  # الشعار الرسمي باللغة العربية
├── logo-en.png                  # الشعار الرسمي باللغة الإنجليزية
├── css/
│   ├── scholar-tokens.css       # توكنز الألوان الصامتة، المقاييس السائلة، والظلال
│   ├── scholar-layout.css       # هندسة التخطيط، شبكة الهيكل (Skeleton Grid)، والـ Viewport
│   ├── scholar-components.css   # بطاقات الخدمات، ملف الإرسال (Dossier)، وحقول الإدخال
│   └── scholar-animations.css   # الحركات الفيزيائية، الماركي، وانتقالات الأكورديون
├── js/
│   ├── three.min.js             # محرك الرسوميات ثلاثية الأبعاد (Three.js Engine)
│   └── scholar-bundle.js        # منطق الـ i18n، مسرح الخدمات 3D، وتوليد روابط الإرسال
├── LICENSE                      # رخصة الاستخدام (MIT License)
└── README.md                    # التوثيق الشامل والمحدث للمنصة
```

## 🚀 التشغيل المحلي (Local Development)

المشروع مبني بلغة الويب النقية ويعمل فوراً بدون أي حزم تثبيت:

```bash
# 1. استنساخ المستودع
git clone https://github.com/MarwanDevSpace/skolar-library.github.io.git
cd skolar-library.github.io

# 2. التشغيل المباشر
start index.html

# أو استخدام خادم محلي خفيف
python -m http.server 3000
```
